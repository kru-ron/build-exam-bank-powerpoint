# สกิลสร้างคลังข้อสอบเคมี PowerPoint (สำหรับ Claude)

สกิลนี้ให้ Claude ช่วย **ถอดข้อสอบจากไฟล์ PDF สแกน/รูป/Word** แล้วจัดเป็นไฟล์ PowerPoint คลังข้อสอบตามสารบัญ ม.ปลาย
แบบ 1 หัวข้อใหญ่ = 1 ไฟล์

## ได้อะไรบ้าง
- กระดาษ A4 แนวตั้ง ฟอนต์ TH SarabunPSK 14
- หน้าแรกมีอินเด็กซ์เป็นตาราง บอกเลขข้อเดิมในหนังสือและจำนวนข้อของแต่ละหัวข้อย่อย
- ข้อสอบเรียงตามหัวข้อย่อย ตัวเลือก ก. ข. ค. ง. ชิดซ้าย ข้อไม่ขาดข้ามหน้า
- ตารางเป็นตาราง PowerPoint จริง กราฟ/แผนภาพวาดใหม่ให้คม แก้ไขได้
- เฉลยท้ายไฟล์ แบบ `1. ก`

> ข้อสอบถอดโดย AI อ่านจากภาพสแกน **ผู้ใช้ควรตรวจทานก่อนนำไปใช้** — Claude จะรายงานจุดที่ควรตรวจท้ายงานทุกครั้ง

## ต้องมีอะไรในเครื่อง
1. เครื่อง **Mac**
2. แอป **Claude** ที่ใช้แท็บ **Code** ได้ (หรือ Claude Code)
3. **Microsoft PowerPoint** (ใช้ส่งออก PDF เพื่อตรวจว่าข้อความไม่ล้นหน้า)
4. ฟอนต์ **TH SarabunPSK** (ดาวน์โหลดฟรี เช่นจาก f0nt.com แล้วดับเบิลคลิกติดตั้ง)

ครั้งแรกที่ใช้ Claude จะขอติดตั้งโปรแกรมเสริมสำหรับอ่าน PDF/สร้าง PowerPoint ให้เอง — กด **อนุญาต (Allow)**

## วิธีติดตั้ง
1. กดปุ่มสีเขียว **Code** ด้านบนหน้านี้ > **Download ZIP** แล้วแตกไฟล์
2. นำโฟลเดอร์ `build-exam-bank-powerpoint` ไปไว้ที่ `~/.claude/skills/`
   (ใน Finder กด Cmd+Shift+G แล้วพิมพ์ `~/.claude/skills` — ถ้ายังไม่มีโฟลเดอร์ `skills` ให้สร้างใหม่)
3. เปิดแอป Claude ใหม่

หรือพิมพ์บอก Claude ว่า "ช่วยติดตั้งสกิลจากลิงก์ GitHub นี้ให้หน่อย" แล้ววางลิงก์หน้านี้

## วิธีใช้
1. เปิดแอป Claude แท็บ Code แล้วเลือกโฟลเดอร์ที่เก็บไฟล์ข้อสอบ PDF
2. พิมพ์ `/build-exam-bank-powerpoint ทำหัวข้อที่ 1` (หรือบอกว่าไฟล์ไหน บทไหน)
3. Claude จะถามยืนยันชื่อโฟลเดอร์ที่จะบันทึกผลก่อนสร้าง แล้วทำทีละหัวข้อ และส่งให้ดูก่อนไปหัวข้อถัดไป

## ปรับแต่ง
- **สารบัญ**: ค่าเริ่มต้นคือสารบัญเคมี ม.ปลาย 12 หัวข้อใน `references/toc-chemistry.md` — ถ้ามีสารบัญของตัวเอง ส่งให้ Claude แล้วบอกให้ใช้แทน
- **ลายน้ำ/ชื่อท้ายหน้า**: เปิด `assets/template.pptx` ใน PowerPoint > View > Slide Master ใส่ชื่อของตัวเอง แล้วบันทึก
- **ตัวอย่าง**: `examples/` มีไฟล์ตัวอย่างที่สร้างคลังข้อสอบ 6 ข้อได้จริง (โจทย์แต่งขึ้นเพื่อสาธิต)

## ข้อควรระวัง
- ใช้กับไฟล์ข้อสอบที่ตัวเองมีสิทธิ์ใช้ และไม่ควรเผยแพร่ข้อสอบที่ถอดจากหนังสือที่มีลิขสิทธิ์
- งานยาว (หนังสือ 100+ ข้อ) ใช้เวลานานและใช้โควตาการใช้งาน Claude มาก
