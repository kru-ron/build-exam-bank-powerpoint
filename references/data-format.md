## 1. ไฟล์บท

```python
Q = []
def q(no, sub, stem, opts_=None, ans=None, **kw):
    d = dict(no=no, sub=sub, stem=stem, opts=kw.pop('opts', opts_), ans=ans); d.update(kw); Q.append(d)
SHARED = []   # ข้อมูลร่วมหลายข้อ
CROPS = {}    # ภาพที่ต้องครอปจาก PDF (ใช้เฉพาะภาพที่วาดเป็นเส้นไม่ได้)

q(12, "5.3", "แก๊สชนิดหนึ่ง ... (H = 1, C = 12)", ["ตัวเลือก 1", "ตัวเลือก 2", "ตัวเลือก 3", "ตัวเลือก 4"])
```

### ฟิลด์ของแต่ละข้อ

| ฟิลด์ | ความหมาย |
|---|---|
| `no` | เลขข้อเดิมในหนังสือ/ข้อสอบ (ใช้ในอินเด็กซ์และที่มา) |
| `sub` | รหัสหัวข้อย่อยตามสารบัญ เช่น `"4.13"`; ข้อที่ไม่แน่ใจใส่ `"รอตรวจหมวด"` |
| `stem` | ข้อความโจทย์ส่วนแรก (ก่อนข้อมูล/ตาราง/รูป) |
| `opts` | รายการตัวเลือกเป็นข้อความ (ไม่ต้องใส่ ก. ข.) — ตัวสร้างใส่ป้าย ก.–จ. เอง |
| `ans` | ตัวเลือกที่ถูก 1–4 (1 = ก) |
| `info` | รายการบรรทัดข้อมูลเยื้อง 1 แท็บ (A. B. C., สมการ, ข้อมูลกำหนด) |
| `table` | ตารางในโจทย์ `dict(rows=[[หัว...],[...]], left_cols=[...])` |
| `mid_img` | ภาพ/รูปวาดใต้โจทย์ (คีย์ใน FIGS หรือชื่อไฟล์ png ในโฟลเดอร์ภาพ) `img_h=` ความสูงภาพครอป |
| `info_after` | ข้อมูลเยื้องที่อยู่หลังตาราง/รูป |
| `table2` | ตารางที่สองหลัง info_after |
| `stem2` | คำถามท้ายโจทย์ (หลังข้อมูล/ตาราง/รูป) |
| `info2`, `stem3` | ข้อมูลชุดที่สองและคำถามหลังจากนั้น (โจทย์ซ้อนชั้น) |
| `img_opts` | ตัวเลือกที่เป็นรูป `["key_1", ...]` วางเรียงแถวพร้อมป้าย ก.–ง. |
| `text_opts_after` | ตัวเลือกข้อความที่ต่อจากตัวเลือกรูป (เช่น "ทั้ง ก และ ข") |
| `opts_table` | ตัวเลือกที่เป็นตาราง — คอลัมน์แรกต้องเป็น "ตัวเลือก" แถวละ ก./ข./ค./ง. |
| `side_img` | รูปเล็กวางขวาของตัวเลือก |
| `subjective=True` | ข้อสอบอัตนัย (ไม่มีตัวเลือก) ใส่คำว่า (ข้อสอบอัตนัย) ท้ายโจทย์ |
| `edit_note` | บันทึกสิ่งที่ปรับจากต้นฉบับ (ก→A, เศษส่วนในบรรทัด, เพิ่มประโยคนำ) — ใช้รายงานผู้ใช้ |
| `dup_note` / `sub_note` | ข้อซ้ำ / เหตุผลการจัดหมวด — ใช้รายงาน |

### มาร์กอัปในข้อความ
- `^{2+}` ตัวยก, `_{2}` ตัวห้อย (ห้ามใช้อักขระ ² ₂)
- `<u>ไม่</u>` ขีดเส้นใต้ (คำปฏิเสธที่ต้นฉบับขีดเส้นใต้)
- `\t` ในบรรทัด `info` = จัดคอลัมน์ด้วยแท็บจริง (ตัวสร้างคำนวณตำแหน่งแท็บให้ทุกบรรทัดในชุดตรงกัน); ช่องว่าง 3 ตัวขึ้นไปจะถูกแปลงเป็นแท็บเช่นกัน
- `\n` ในเซลล์ตาราง = ขึ้นบรรทัดใหม่ในเซลล์
- เซลล์ตาราง `None` = ช่องว่างไม่มีเส้นกรอบ, `'~ข้อความ'` = ข้อความไม่มีกรอบ (ใช้ทำตารางธาตุ), `''` = ช่องว่างมีกรอบ
- ตารางไม่มีแถวหัว: `noheader=True`; ความกว้างคงที่: `cols=[..], fixed=True`

### ข้อมูลร่วมหลายข้อ (คำชี้แจง)
```python
SHARED.append(dict(first=24, last=25, text="ข้อมูลต่อไปนี้ใช้ตอบคำถามข้อ {a}–{b}",
                   lines=[...], img="key", img_h=90, table=dict(...), lines_after=[...]))
```
`{a}` `{b}` จะถูกแทนด้วย *เลขข้อใหม่* อัตโนมัติ (ถ้าข้อเดียว/สองข้อ จะเขียน "ข้อ 5" / "ข้อ 5 และ 6")
ข้อที่อยู่ในช่วงจะถูกจัดเป็นก้อนเดียวไม่ฉีกข้ามสไลด์

### เฉลย
ท้ายไฟล์บท:
```python

_A = [int(x) for x in _A.split()]; assert len(_A) == จำนวนข้อ

for d in Q: ...
```
เฉลยที่ไม่แน่ใจ: `ans_note = "รอตรวจ (เหตุผล)"` ห้ามเดา

## 2. ไฟล์หัวข้อใหญ่

```python
import copy, book1_ch4 as C4, book1_ch5 as C5, figs5
BOOK  = "ชื่อหนังสือ บทที่ 4"            # แหล่งหลัก
BOOKS = ["ชื่อหนังสือ บทที่ 4", "ชื่อหนังสือ บทที่ 5"]   # 1 คอลัมน์อินเด็กซ์ต่อแหล่ง (เรียงตามที่ผู้ใช้กำหนด)
TOPIC_NO, TOPIC_NAME = 5, "โมล ปริมาณสารสัมพันธ์ และสารละลาย"
SUBTOPICS = [("5.1", "มวลอะตอม"), ...,  ("รอตรวจหมวด", "ข้อสอบรอตรวจหมวด")]   # ครบทุกหัวข้อตามสารบัญ
codes = {c for c, _ in SUBTOPICS}
Q = []
for src, B in ((C4, BOOKS[0]), (C5, BOOKS[1])):
    for q in src.Q:
        if q['sub'] in codes: d = copy.deepcopy(q); d['book'] = B; Q.append(d)
SHARED = [dict(sh, book=BOOKS[0]) for sh in C4.SHARED] + [dict(sh, book=BOOKS[1]) for sh in C5.SHARED]
FIGS = figs5.DEFS
NOTE_INDEX = "หมายเหตุใต้หัวเรื่อง (ข้อที่ไปอยู่หัวข้ออื่น, ข้อซ้ำที่ไม่พิมพ์ ฯลฯ)"
```
- `ข้อสอบรอตรวจหมวด` / `ข้อสอบนอกสารบัญ` ใส่ใน SUBTOPICS เป็นหัวข้อพิเศษ (แสดงเฉพาะเมื่อมีข้อ)
- ข้อซ้ำทุกตัวอักษร ให้ตัดออก 1 ข้อและเขียนใน NOTE_INDEX

## 3. รูปวาด (FIGS)

ไฟล์ `figsN.py` มี `DEFS = {key: ฟังก์ชัน(F)}` ฟังก์ชันวาดด้วยวัตถุ `F` (คลาส Fig ใน build_bank.py) หน่วยเป็นพิกเซลของภาพต้นฉบับ แล้ว `F.scale(s)` แปลงเป็น pt

| คำสั่ง | ผล |
|---|---|
| `F.scale(0.5)` | ตัวคูณจากหน่วยที่ใช้ → pt |
| `F.line(x1,y1,x2,y2, arrow=1, dash=1, w=1.25)` | เส้น/ลูกศร/เส้นประ |
| `F.rect(x,y,w,h, fill='000000')` | สี่เหลี่ยม |
| `F.ell(cx,cy,rx,ry, fill=...)` | วงรี/จุด |
| `F.path([(x,y),...], closed=1, smooth=1, fill=...)` | เส้นหลายจุด/โค้ง/รูปหลายเหลี่ยม |
| `F.arc(cx,cy,r,a0,a1)` | ส่วนโค้งวงกลม (องศา) |
| `F.text('Na^{+}', cx, cy, sz=12, al='ctr'/'l'/'r', rot=-90, color='FFFFFF')` | ป้ายข้อความ TH SarabunPSK ตัวยกห้อยจริง |
