# สารบัญเคมี ม.ปลาย 12 หัวข้อใหญ่ (ค่าเริ่มต้น — ถ้าผู้ใช้ส่งสารบัญของตัวเองมา ให้ใช้ของผู้ใช้แทน)

หัวข้อที่ 1 ความปลอดภัย
1.1 ฉลากสารเคมี 1.2 สัญลักษณ์ GHS 1.3 สัญลักษณ์ NFPA 1.4 ฉลากสารเคมี 1.5 การปฏิบัติตนในห้องทดลอง 1.6 การเจือจางกรด 1.7 การจัดการของเสีย 1.8 อุบัติเหตุและการปฐมพยาบาล 1.9 ความเที่ยงและความแม่น 1.10 การเลือกอุปกรณ์วัดปริมาตร 1.11 การอ่านสเกลและผิวโค้ง 1.12 การใช้บิวเรตต์ 1.13 การชั่งมวล 1.14 ความหนาแน่น 1.15 เลขนัยสำคัญ 1.16 สัญกรณ์วิทยาศาสตร์ 1.17 การปัดเลข 1.18 การคำนวณ 1.19 ค่าเฉลี่ย 1.20 หน่วย SI และการเปลี่ยนหน่วย 1.21 วิธีการทางวิทยาศาสตร์และตัวแปร
(1.1 กับ 1.4 ชื่อซ้ำ — ใส่ข้อเรื่องฉลากที่ 1.1)

หัวข้อที่ 2 อะตอม
2.1 โครงสร้างอะตอม 2.2 แบบจำลองอะตอม 2.3 อนุภาคมูลฐาน 2.4 เลขอะตอม เลขมวล และไอโซโทป 2.5 การจัดเรียงอิเล็กตรอน 2.6 ระดับพลังงานและออร์บิทัล

หัวข้อที่ 3 ตารางธาตุ
3.1 วิวัฒนาการของตารางธาตุ 3.2 ขนาดอะตอมและการเปรียบเทียบขนาดอะตอม 3.3 ขนาดไอออนและการเปรียบเทียบขนาดไอออน 3.4 แนวโน้มค่าต่าง ๆ = EN, EA, IE, E° 3.5 แนวโน้มสมบัติทางกายภาพ = ความหนาแน่น, ความเป็นโลหะ, จุดเดือด 3.6 เลขออกซิเดชัน 3.7 สมบัติของสารประกอบคลอไรด์และออกไซด์ 3.8 สมบัติของธาตุตามหมู่ 3.9 ตำแหน่งของไฮโดรเจน 3.10 ธาตุแทรนซิชัน 3.11 สารเชิงซ้อน 3.12 ธาตุกัมมันตรังสีและการคำนวณครึ่งชีวิต 3.13 การใช้ประโยชน์ของธาตุกัมมันตรังสี

หัวข้อที่ 4 พันธะเคมี
4.1 พันธะเคมีภาพรวม = การเกิดพันธะ, ระยะระหว่างอะตอมและพลังงาน, แรงยึดเหนี่ยวภายในและระหว่างโมเลกุล 4.2 พันธะโลหะ = การเกิด, สมบัติ 4.3 พันธะไอออนิก = การเกิด, สมบัติ 4.4 สูตรและชื่อสารประกอบไอออนิก = การเขียนสูตร, การอ่านชื่อ 4.5 การละลายน้ำของสารประกอบไอออนิก 4.6 การเปลี่ยนแปลงของสาร = การเปลี่ยนแปลงทางกายภาพ, การเปลี่ยนแปลงทางเคมี 4.7 การเปลี่ยนแปลงพลังงาน = ปฏิกิริยาดูดพลังงาน, ปฏิกิริยาคายพลังงาน 4.8 พลังงานในการละลายสารประกอบไอออนิก = พลังงานแลตทิซ, พลังงานไฮเดรชัน 4.9 สมการไอออนิก = สมการไอออนิก, สมการไอออนิกสุทธิ 4.10 พันธะโคเวเลนต์ = การเกิด, สมบัติ 4.11 การอ่านชื่อสารโคเวเลนต์ = สารประกอบโคเวเลนต์, กรด 4.12 สูตรโครงสร้าง = สูตรลิวอิส, จำนวนพันธะ, กฎออกเตต, อิเล็กตรอนคู่โดดเดี่ยว 4.13 มุมพันธะและรูปร่างโมเลกุล 13 แบบ 4.14 สภาพขั้ว = สภาพขั้วของพันธะ, สภาพขั้วของโมเลกุล 4.15 แรงยึดเหนี่ยวระหว่างโมเลกุล = พันธะไฮโดรเจน, แรงไดโพล–ไดโพล, แรงลอนดอน 4.16 การเปรียบเทียบจุดเดือด 4.17 โครงผลึกร่างตาข่ายและจุดเดือด 4.18 เรโซแนนซ์ 4.19 พลังงานพันธะ = การทำนายปฏิกิริยาดูด/คายพลังงาน, การคำนวณพลังงานพันธะ

หัวข้อที่ 5 โมล ปริมาณสารสัมพันธ์ และสารละลาย
5.1 มวลอะตอม 5.2 มวลอะตอมสัมพัทธ์ 5.3 โมล = จำนวนอนุภาค, มวล, ปริมาตรแก๊ส 5.4 สูตรเอมพิริคัลและสูตรโมเลกุล 5.5 ร้อยละ = %w/w, %v/v, %w/v 5.6 ppm และ ppb 5.7 ความเข้มข้น = mol/dm³, mol/kg, เศษส่วนโมล 5.8 การเตรียมสารละลาย = การเตรียมจากของแข็ง, การเจือจาง, การผสมสารละลาย 5.9 สมบัติคอลลิเกทีฟ = การลดลงของความดันไอ, การเพิ่มขึ้นของจุดเดือด, การลดลงของจุดเยือกแข็ง, ความดันออสโมติก 5.10 การดุลสมการเคมี 5.11 ปริมาณสารสัมพันธ์ 5.12 สารกำหนดปริมาณและสารเหลือ 5.13 ผลได้ร้อยละ

หัวข้อที่ 6 แก๊ส
6.1 ทฤษฎีจลน์ของแก๊ส = ข้อสมมติ 5 ข้อ, แก๊สอุดมคติ, แก๊สจริง 6.2 กฎของแก๊ส = บอยล์, ชาร์ล, อาโวกาโดร, เกย์-ลูสแซก 6.3 กฎรวมแก๊ส = P₁V₁/T₁ = P₂V₂/T₂ 6.4 ความสัมพันธ์ระหว่างปริมาตรกับจำนวนโมล = V₁/n₁ = V₂/n₂ 6.5 กฎแก๊สอุดมคติ = PV = nRT 6.6 ความหนาแน่นของแก๊ส = d = PM/RT 6.7 ความดันรวมและความดันย่อย = กฎของดอลตัน, เศษส่วนโมล 6.8 แก๊สผสม = PรวมVรวม = nรวมRT 6.9 ปริมาณสารสัมพันธ์ของแก๊ส 6.10 การแพร่ของแก๊สและการเปรียบเทียบอัตราการแพร่ 6.11 การคำนวณอัตราการแพร่ของแก๊ส = กฎของเกรแฮม

หัวข้อที่ 7 อัตราการเกิดปฏิกิริยาเคมี
7.1 สูตรอัตราการเกิดปฏิกิริยา 7.2 อัตราของสารและอัตราของปฏิกิริยา 7.3 การเปรียบเทียบอัตรา 7.4 กราฟอัตราการเกิดปฏิกิริยา 7.5 การคำนวณอัตราจากตาราง 7.6 การคำนวณอัตราจากกราฟ 7.7 ทฤษฎีการเกิดปฏิกิริยา 7.8 แผนภาพพลังงานและพลังงานก่อกัมมันต์ 7.9 กลไกการเกิดปฏิกิริยา 7.10 ปัจจัยที่มีผลต่ออัตราการเกิดปฏิกิริยา 7.11 การวิเคราะห์ปัจจัยและเหตุผล 7.12 กฎอัตรา

หัวข้อที่ 8 สมดุลเคมี
8.1 การเกิดสมดุลเคมี = เงื่อนไขการเกิดสมดุล 4 ข้อ 8.2 ค่าคงที่สมดุล Kc 8.3 ความสัมพันธ์ระหว่างสมการกับค่าคงที่สมดุล 8.4 การคำนวณค่าคงที่สมดุล = ให้ค่าที่สมดุลมาครบ, ให้ค่าที่สมดุลมาบางค่า, ร้อยละ, หลายสมการ 8.5 ค่าคงที่สมดุลความดัน Kp = จากความดันย่อย, Kp = Kc(RT)^Δn 8.6 การรบกวนสมดุล = ความเข้มข้น, ความดัน/ปริมาตร, อุณหภูมิ, ตัวเร่งปฏิกิริยา 8.7 การคำนวณเมื่อมีการรบกวนสมดุล

หัวข้อที่ 9 กรด–เบส
9.1 ชนิดของกรด–เบส 9.2 ชนิดของสาร = อิเล็กโทรไลต์, นอนอิเล็กโทรไลต์ 9.3 ทฤษฎีกรด–เบส = Arrhenius, Brønsted–Lowry, Lewis 9.4 คู่กรด–เบส 9.5 กรด เบส และแอมโฟเทอริก 9.6 การจำแนกชนิดของกรดและเบส = ตามองค์ประกอบ, ตามจำนวน H⁺/OH⁻ ที่แตกตัว, ตามความสามารถในการแตกตัว 9.7 ความแรงของกรด–เบส 9.8 การแปลงหน่วย = [H⁺], [OH⁻], pH, pOH 9.9 การคำนวณกรดแก่และเบสแก่ 9.10 การคำนวณกรดอ่อนและเบสอ่อน 9.11 การแตกตัวของกรด–เบสชนิดเดียวกัน 9.12 ค่า Ka/Kb กับการแตกตัว 9.13 อินดิเคเตอร์กรด–เบส 9.14 การหาช่วง pH ของอินดิเคเตอร์ 9.15 ปฏิกิริยาของกรด–เบส 9.16 ชนิดของเกลือ 9.17 ปฏิกิริยาไฮโดรลิซิส 9.18 ความสัมพันธ์ Ka, Kb และ Kw 9.19 การคำนวณ pH ของเกลือ 9.20 สารละลายบัฟเฟอร์ 9.21 การคำนวณ pH ของบัฟเฟอร์ 9.22 การไทเทรตกรด–เบส 9.23 กราฟการไทเทรต 9.24 ค่า K กับกราฟการไทเทรต 9.25 การเลือกอินดิเคเตอร์ในการไทเทรต 9.26 การคำนวณ pH ของสารผสม

หัวข้อที่ 10 ไฟฟ้าเคมี
10.1 เลขออกซิเดชัน 10.2 ปฏิกิริยารีดอกซ์ = ออกซิเดชัน, รีดักชัน, ตัวออกซิไดซ์และตัวรีดิวซ์ 10.3 การพิจารณาว่าเป็น/ไม่เป็นปฏิกิริยารีดอกซ์ 10.4 การดุลสมการรีดอกซ์ 10.5 ศักย์รีดักชันมาตรฐาน E° = ค่า E°, การเปรียบเทียบค่า E°, โลหะจุ่มในสารละลาย 10.6 แผนภาพเซลล์ 10.7 เซลล์กัลวานิก 10.8 การคำนวณ E°cell 10.9 การทำนายการเกิดปฏิกิริยารีดอกซ์ 10.10 เซลล์อิเล็กโทรไลต์ 10.11 การแยกสารด้วยกระแสไฟฟ้า 10.12 การชุบโลหะ 10.13 การทำโลหะให้บริสุทธิ์ 10.14 การป้องกันการกัดกร่อนแบบแคโทดิก
(เลขออกซิเดชัน: ถามแนวโน้มตามตารางธาตุ → 3.6, ใช้กับรีดอกซ์ → 10.1)

หัวข้อที่ 11 เคมีอินทรีย์
11.1 พันธะของสารประกอบอินทรีย์ รวมถึงจำนวนอิเล็กตรอนคู่โดดเดี่ยว 11.2 สูตรโครงสร้างของสารอินทรีย์ 11.3 หมู่ฟังก์ชัน 11.4 การเรียกชื่อสารอินทรีย์ (แอลเคน, แอลคีน, แอลไคน์, อะโรมาติก, แอลกอฮอล์, อีเทอร์, แอลดีไฮด์, คีโตน, กรดคาร์บอกซิลิก, เอสเทอร์) 11.5 ไอโซเมอร์ 11.6 สมบัติทางกายภาพสารอินทรีย์ = สภาพขั้ว, การละลาย, จุดเดือด 11.7 ปฏิกิริยาของสารประกอบไฮโดรคาร์บอน (การเผาไหม้, กับสารละลายโบรมีน (การเติมและแทนที่), กับ KMnO₄) 11.8 ปฏิกิริยาของสารประกอบอินทรีย์ (เอสเทอริฟิเคชัน, สะปอนนิฟิเคชัน, เอไมด์, ไฮโดรไลซิสเอไมด์)
